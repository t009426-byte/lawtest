## 3️⃣ قاعدة عدم استخدام مصادر خارجية

### ✅ يجب عدم الوصول إلى:
- ❌ Google و Google Search
- ❌ الإنترنت بشكل عام
- ❌ Wikipedia
- ❌ مواقع قانونية (مثل Justia, LawInsider)

## 5️⃣ حالات الاستخدام

### الحالة 1: المستخدم الجديد
```
1. افتح المنصة
2. رفع ملف PDF بقانون جزائي
3. انسخ ولصق نصاً قانونياً
4. اذهب إلى توليد الأسئلة
5. اضغط "توليد"
6. اختبار النتائج
```

### الحالة 2: الاختبار الكامل
```
1. رفع 3 ملفات قانونية
2. توليد 40 سؤال
3. ابدأ الاختبار (45 دقيقة)
4. أجب على جميع الأسئلة
5. تسليم الاختبار
6. اعرض النتائج والتحليل
```

### الحالة 3: إعادة الاختبار
```
1. اختبر مرة
2. عرض النتائج
3. انقر "إعادة الاختبار"
4. امسح الإجابات السابقة
5. ابدأ اختبار جديد
```
